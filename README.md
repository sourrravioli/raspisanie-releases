# расписание

Неофициальное приложение-расписание для студентов Сеченовского университета (Android).

> ## ⚠️ Приложение НЕ является официальным приложением университета и не связано с ним.
> ## Вы входите своим логином и паролем от ЛКО на свой страх и риск.

Что умеет: расписание из личного кабинета (ЛКО) в календаре, обратный отсчёт до ЦТ и экзаменов, напоминания, заметки к парам, пропуски и отработки, подготовка к аттестациям, виджет на рабочий стол. Работает и без интернета — показывает последнее сохранённое расписание.

Нужен телефон на **Android 8.0 или новее**. Версии для iPhone нет.

---

## Как установить в первый раз

1. Откройте на телефоне страницу **[Releases](../../releases)** этого репозитория.
2. В самой верхней версии (с пометкой **Latest**) в разделе **Assets** нажмите на файл **`raspisanie-….apk`**. Он скачается.
   Файл `update.json` скачивать не нужно — он для самого приложения.
3. Откройте скачанный файл (из уведомления о загрузке или из приложения «Файлы» → «Загрузки»).
4. Телефон может сказать, что установка из этого источника запрещена. Нажмите **«Настройки»** и включите **«Разрешить из этого источника»** для браузера или «Файлов», через которые открываете файл. Вернитесь назад.
5. Нажмите **«Установить»**.
6. Если появится предупреждение **Play Защиты** («Приложение не проверено» / «Небезопасное приложение»): нажмите **«Подробнее»** → **«Всё равно установить»**. Оно появляется, потому что приложение не из Google Play.
7. Откройте приложение и войдите почтой и паролем от ЛКО — теми же, что на student.sechenov.ru. Если вход не получается, есть кнопка **«Войти через сайт»**: откроется настоящая страница входа ЛКО.

**Дальше обновления приходят в самом приложении:** появится уведомление и плашка «Есть обновление», обновление ставится одной кнопкой. Первый раз Android попросит разрешить приложению «Установку неизвестных приложений» — приложение объяснит, где это включить.

## Безопасность и данные

- **Логин и пароль** хранятся только на вашем телефоне, в зашифрованном виде: ключ шифрования лежит в защищённом хранилище Android и не покидает телефон. Отправляются они только на student.sechenov.ru — так же, как при входе через браузер. При «Войти через сайт» пароль приложение не сохраняет вовсе.
- **У приложения нет своего сервера.** Расписание, профиль, документы, заметки, файлы, пропуски и подготовка хранятся только на телефоне. Разработчик их не видит и не получает. В облачные резервные копии Android приложение свои данные не отдаёт.
- **Куда приложение ходит в интернет:**
  - **student.sechenov.ru** — вход, расписание, профиль, документы. Обращения к другим адресам приложение для этого не делает: это ограничено в самом коде.
  - **Окно ЭОР** — встроенный браузер: открывает ссылку на ЭОР со страницы ЛКО. Внутри него можно перейти по ссылкам на другие сайты, как в обычном браузере.
  - **github.com** (и его сервер для файлов) — только чтобы проверить, есть ли новая версия, и скачать её. Приложение лишь скачивает файл с описанием версии и сам APK. Как любой сайт, GitHub видит технические данные запроса (например, IP-адрес), но никакие данные из приложения туда не передаются.
- **Нет рекламы, аналитики и сборщиков статистики** в коде приложения.
  **Автоматических отчётов об ошибках нет.** Если что-то сломалось, можно отправить отчёт вручную: вы увидите весь его текст перед отправкой, личных данных в нём нет.
  Исключение — **сканер документов** во вкладке «Профиль»: это компонент Google Play services (от Google). Скан делается на телефоне, но Google по своим правилам может получать технические сведения об использовании сканера. Если не хотите — добавляйте документы фотографией или файлом, без сканера.
- **Приложение только читает данные из ЛКО** и ничего на сайте не меняет и не отправляет — кроме самого входа. Если вы сами что-то делаете в окне ЭОР (например, проходите тест), это как в обычном браузере.
- **Как удалить свои данные:**
  - **«Настройки → Аккаунт → Выйти»** удаляет пароль и вход (в том числе вход в окне ЭОР). Если там же отметить **«Удалить также расписание, заметки, подготовку и файлы»** — удалится и это.
  - **Удаление приложения** удаляет всё.
- **Обновления подписаны одним ключом:** Android не даст поставить поверх приложения подделку, подписанную чужим ключом. Перед установкой приложение ещё и сверяет контрольную сумму скачанного файла.
  **Скачивайте приложение ТОЛЬКО со страницы [Releases](../../releases) этого репозитория.**

## Какие разрешения просит приложение и зачем

| Разрешение | Зачем |
|---|---|
| Уведомления | Напоминания об аттестациях, сводка на завтра, отработки, обновления. |
| Будильники и напоминания (точное время) | Чтобы напоминания приходили вовремя, а не с опозданием. |
| Запуск после перезагрузки | Заново поставить напоминания после перезагрузки телефона. |
| Работа без ограничений батареи (по кнопке в настройках) | Чтобы телефон не «усыплял» фоновое обновление расписания. |
| Доступ к «Не беспокоить» (только если включить «Тихий режим на парах») | Сделать телефон тихим на время пары и потом вернуть звук. |
| Установка неизвестных приложений | Ставить обновления из самого приложения. |
| Интернет | Ходить на student.sechenov.ru и проверять обновления. |

**Камера:** отдельного разрешения на камеру приложение не просит. Для фото и сканов оно открывает приложение камеры телефона или сканер Google.
